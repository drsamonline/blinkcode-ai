Point your camera, get the file.

BlinkCode AI compresses a file into a compact File DNA container, paints it as SpectraCode colour matrices, and recovers it by pointing a camera at the sender's screen. No server, no network after the first launch.

Open the app View source

What it does

Colour, not black and white

36 reference colours, five bits per cell — a single SpectraCode frame holds kilobytes where a QR holds hundreds of bytes.

Real compression

An order-1 arithmetic coder with a match (LZP) model, plus a lossy perceptual image mode for photos.

Built to survive

Reed-Solomon RS(255,223) repairs up to 16 damaged bytes per block; the decoder fits a colour-correction matrix from a calibration strip.

Offline-first PWA

The model bundle downloads once and is cached. After that the app never touches the network.

How it works

file ─▶ arithmetic coder ─▶ File DNA ─▶ frames ─▶ RS(255,223) ─▶ colour grid
                                                                      │
        file ◀─ arithmetic decoder ◀─ CRC-32 ◀─ collector ◀─ RS ◀──────┘
                                              ▲
        camera ─▶ bullseye detect ─▶ homography ─▶ colour correction ─▶ classify

The match model added ~31% over the original order-1 coder. It cannot beat entropy — random data stays at ~1× — and the app says so plainly.

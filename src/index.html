How it works

        
    
          
  1. One-time model download. A Universal Compression Graph bundle is fetched once and kept in Cache Storage and IndexedDB. Every later launch is fully offline.
    2. 
          
  2. File DNA. Bytes are compressed with an order-1 context model driving an arithmetic coder. Images can instead be reduced to a 64-value perceptual latent.
    3. 
          
  3. SpectraCode. The container is Reed-Solomon protected (RS 255,223) and painted as a 120×80 grid of 32 palette colours with four bullseye markers and a 36-colour calibration strip.
    4. 
          
  4. One shot. The receiver photographs a single frame, warps it with a homography from the marker centres, fits a colour-correction matrix from the strip, classifies every cell and rebuilds the file.
    5. 
        

        
Honest limits

        

          One SpectraCode carries 5,129 bytes of compressed payload — no compressor can push an
          arbitrary large file below that, because lossless compression cannot beat the entropy of the data.
          Real ratios here are roughly 2–4× on text and source code, ~1× on already-compressed data (JPEG, ZIP, MP4),
          and 1000×+ only in perceptual image mode, which throws away detail and returns a 32×32-detail
          reconstruction rather than the original photo.
